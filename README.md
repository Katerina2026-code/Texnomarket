# Texnomarket
Самописная конфигурация на платформе "1С:Предприятие 8.5" для автоматизации магазина(складской учет, заказы клиентов, взаиморасчеты) обмен данными по протоколу CommerceML с сайтом на "1С-Битрикс".
* src - выгрузка конфигурации в файлы (включая общий модуль обмена с сайтом "ОбменССайтомСервер").
* shema.png - схема метаданных базы.
* База работает в файловом режиме на платформе "1С:Предприятие 8.5" (Версия для разработчиков). Тестовый сайт "1С-Битрикс" развернут локально в docker.
